and returns the target `System`. Export the result with the target model package.

`system` must contain the source component classes and time series expected by
the workflow. An empty `System` is not a complete model. Configuration classes
resolve source and target models through their `models` field.

## Hydro budget resolution

`ReedsToPlexosConfig.hydro_budget_ts` defaults to `"daily"`.
`SiennaToPlexosConfig.hydro_budget_ts` defaults to `"weekly"`.
Both accept `"hourly"`, `"daily"`, `"weekly"`, and `"monthly"`.

The property-reference pages link to each package's `config/rules.json`, which
specifies direct fields, computed getters, filters, and defaults. Use the
configuration and implementation links above for the complete current contract.

For shared `System`, `PluginContext`, rule, and plugin APIs, see
[r2x-core](https://natlabrockies.github.io/r2x-core/).
