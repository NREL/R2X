R2X provides translation plugins for ReEDS, PLEXOS, and Sienna model interoperability.

This repository contains the translation layer in the [`r2x-cli`](https://github.com/NatlabRockies/r2x-cli) ecosystem. For the shared plugin architecture, rule engine, `System`, `DataStore`, and units, see [`r2x-core`](https://nrel.github.io/r2x-core/).

## Start here

- [Getting started](/tutorials/getting-started/) explains installation and how to choose a translation workflow.
- [Translation workflows](/how-to/) contains end-to-end Python examples.
- [Architecture](/explanation/architecture/) explains the parser, translation, and exporter boundaries.
- [Development](/how-to/development/) covers checks, adding translation directions, and maintaining translated documentation.
